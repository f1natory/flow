## About

FlowUI makes Minecraft's interface feel smoother without replacing its
original design. It adds short, responsive animations to frequently used UI
elements while keeping the vanilla behavior intact.

No menus are redesigned. No gameplay mechanics are changed. Everything simply
flows a little better.

## Features

### Animated containers

Inventories, chests, crafting tables, furnaces and other container screens
open with a quick scale animation. The interface background, slots, items and
player model move together as a single window.

### Smooth hotbar selection

The selected-slot indicator glides between hotbar slots instead of instantly
jumping to its new position.

### Animated player list

The player list smoothly slides in from the top of the screen and slides back
out when closed. Its original content and behavior remain unchanged.

## Design goals

- **Vanilla-friendly**: preserves Minecraft's original visual language.
- **Responsive**: animations are short and do not slow down interaction.
- **Lightweight**: focused only on interface animation.
- **Client-side**: servers and other players do not need to install FlowUI.

## Installation

1. Install Fabric API.
2. Download a FlowUI version compatible with your Minecraft version from
   [Modrinth](https://modrinth.com/project/flowui).
3. Place the FlowUI JAR in your Minecraft `mods` folder.
4. Launch the game using your Fabric profile.

## Issues and feedback

If an interface from Minecraft or another mod behaves incorrectly with FlowUI,
include the following information in your report:

- Minecraft version;
- FlowUI version;
- Fabric Loader and Fabric API versions;
- installed UI or rendering mods;
- screenshot, video or game log showing the problem.

Report issues on [GitHub](https://github.com/f1natory/flow/issues).
